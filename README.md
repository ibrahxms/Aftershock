**An interactive earthquake tracking dashboard with live seismic data, a world map, and a 3D globe.**

Aftershock is a web-based earthquake monitoring dashboard that lets users explore recent seismic activity around the world. It combines live earthquake information from public data sources with an interactive map, a 3D globe, activity statistics, and customizable shake alerts.

## ✨ Features

- 🌍 **Interactive World Map** — Explore earthquake locations around the globe.
- 🌐 **3D Globe** — View seismic activity on a globe.
- 📡 **Live Earthquake Data** — Uses public USGS and EMSC data sources.
- 📊 **Activity Statistics** — View earthquake counts, strongest events, and latest activity.
- 🔔 **Shake Alerts** — Set a magnitude threshold and test the alert effect.
- 🕒 **Global Time Zones** — View world clocks and UTC time.
- 🎨 **Multiple Map Styles** — Choose between dark, colorful, light, and satellite styles.
- ⚙️ **Custom Filters** — Filter earthquakes by magnitude and time period.
- 📱 **Responsive Design** — Designed to work across different screen sizes.

## 🛠️ Built With

- HTML
- CSS
- JavaScript
- Leaflet
- Public USGS and EMSC earthquake data

## 🚀 Getting Started

No complicated installation is required.

1. Clone or download this repository.
2. Open the project folder.
3. Open `aftershock.html` in your web browser.
4. Explore earthquake activity around the world.

## 📡 Data Sources

Aftershock uses publicly available earthquake information from:

- [USGS Earthquake Hazards Program](https://earthquake.usgs.gov/)
- [European-Mediterranean Seismological Centre (EMSC)](https://www.emsc-csem.org/)

## ⚠️ Disclaimer

Aftershock is an informational earthquake tracking project. It is **not an early-warning system** and should not be used for emergency decisions. Earthquake information may be delayed, revised, or inaccurate.

For safety information and official emergency alerts, follow your local authorities.
